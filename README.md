✈️ Flight Data Analysis & Insights Dashboard

📌 Project Overview

The Flight Data Analysis Dashboard is an interactive data analytics project developed using Microsoft Power BI. The main purpose of this project is to analyze flight operations, airline performance, departure delays, flight distances, and destination patterns through interactive visualizations.

The project transforms raw flight data into meaningful insights that help users understand airline performance, identify flight trends, and explore operational patterns.

The dashboard consists of two interactive pages:

Flight Data Analysis
Flight Insights
Both pages provide different perspectives of flight operations using charts, KPI-style visualizations, and interactive filters.

🎯 Problem Statement

Flight datasets contain large amounts of information related to airlines, destinations, departure delays, flight distances, and monthly flight operations.

Analyzing this information manually can be difficult and time-consuming.

This project aims to solve this problem by developing an interactive Power BI dashboard that presents important flight-related information in a simple, visual, and understandable format.

🎯 Project Objectives

Analyze flight distribution across different months.
Identify airlines with higher average departure delays.
Find the most frequently visited destinations.
Compare average flight distances among airlines.
Analyze monthly flight operations by airline.
Explore flight status and distribution patterns.
Provide interactive data exploration using filters and slicers.
Convert raw flight data into useful business insights.

📊 Dashboard Development

Flight Data Analysis
This page provides an overview of flight operations and airline performance.

Visualizations Included:

Monthly Flight Analysis: Displays the distribution of flights across different months.
Average Departure Delay by Airline: Compares average departure delays among airlines.
Top Destinations by Flight Count: Identifies destinations with the highest number of flights.
Average Flight Distance by Airline: Compares average flight distances across airlines.
Monthly Flights by Airline: Shows monthly flight distribution for different airlines using a stacked column chart.
Flight Insights
This page focuses on exploring specific flight-related insights.

Visualizations Included:

Top 10 Airlines by Average Departure Delay: Highlights airlines based on average departure delay.
Flight Status Analysis: Presents the distribution of flight statuses.
Flight Distribution Analysis: Provides an overview of flight-related distribution patterns.
Interactive Month Selection: Allows users to explore data for selected months.
Destination Filter: Enables destination-based analysis.
📈 Key Analytical Insights

The dashboard helps users explore the following areas:

Airline Performance: Compare airlines based on their average departure delays.
Destination Analysis: Identify destinations with higher flight frequencies.
Monthly Trends: Understand changes in flight activity across different months.
Flight Distance: Compare the average distances covered by different airlines.
Flight Distribution: Explore flight status and operational patterns.
These insights support a better understanding of airline operations and flight activity.

⚙️ Interactive Features

The dashboard includes interactive elements to improve the user experience.

Month slicer for time-based analysis.
Destination selection filter.
Dynamic chart interactions.
Cross-filtering between visualizations.
Airline-based comparisons.
Users can select different filters and explore the data according to their requirements.
